# 完整流程示例

一次真实风格的预测协作，按 SKILL.md 的 8 步走完。领域是「实习选择」，只是示范，不要套数字。

---

## 用户开场

> 我手上有第二份实习邀约，AI 应用方向，远程，但是日薪没说。要不要去？我有点纠结。

## 步骤 0 / 判断

`[步骤 0 / 判断] 走 or 不走：走`
理由：这不是「确认题」，是「该不该」的预测题，且涉及不可逆的时间投入。

---

## 步骤 1 / 决策识别

`[步骤 1 / 决策识别]`

我的反问：

1. 你说的「要不要去」，是和「第一份已通过的实习」二选一，还是和「不实习自己做 AI 产品」二选一？
2. 你想从这份实习带走的最关键的一样东西是什么：钱、case、人脉、还是「试过 AI 行业」的信号？

（用户回答：和第一份二选一；想要的是「能写进简历的 case + 接触 LLM API 真实业务」）

底层真问题：**在 2026 暑假这段时间内，第二份实习相对第一份能多带走 1 个可写进简历的 AI 应用 case 的概率有多大？**

---

## 步骤 2 / 费米化

`[步骤 2 / 费米化]`

- Q1（截止 2026-07-15）：开始实习两周内，第二份是否明确给我接触 LLM API 的具体业务任务？
- Q2（截止 2026-08-15）：是否产出至少 1 个可以放进简历的独立项目 / 模块（不是「参与了 X」）？
- Q3（截止 2026-08-31）：实习结束时，是否能拿到一个公开可展示的链接 / 产品 / 文档？

每条都 yes/no 可判定，截止日明确。

---

## 步骤 3 / 参考类

`[步骤 3 / 参考类]`

**web_search 结果**（虚构示例，不要直接信）：

- 数据点 1：2025 年 boss 直聘「AI 应用实习生」岗位描述抽样 50 条，明确写「会接触 LLM API」的占 62%（来源：[链接]）
- 数据点 2：知乎专栏「AI 创业公司实习生真实产出」，10 个案例中，3 个月内能拿到独立 case 的占 4/10（来源：[链接]）

数据有了，但用户的具体公司没搜到。**进第二段**。

BROK 提示词（粘去豆包专家模式）：

```
# Background
我是***REMOVED***计算机大一学生（跨专业），2026-06 收到一家 AI 应用方向的实习邀约（远程，公司名 XXX）。
我已通过另一份实习，二选一。
我想搞清楚这家公司给实习生的真实任务密度和产出可见性。

# Role
请扮演一位关注 2025 到 2026 年 AI 应用创业公司招聘动态的行业观察者。

# Objective
搜集 XXX 公司的以下信息：
1. 该公司过去 12 个月发过的实习岗 JD（岗位职责具体到哪一项）
2. 是否有公开的「实习生项目展示」（GitHub / 产品页 / 公众号案例）
3. 在脉脉 / 小红书 / 知乎搜「XXX 实习」的真实评价 3 条（含日期）
4. 公司公开的产品形态（C 端 / B 端 / 工具 / Agent）

# Key Result
- 每条信息附独立来源链接
- 评价至少 1 条负面
- 信息时间限定 2025-06 后
- 搜不到的明说，不编
```

（用户粘回豆包结果，假设拿到：公司过去 12 个月发过 4 条实习 JD 都明确写「负责 LLM 接入相关需求」；有 1 个公开实习生案例；脉脉评价 2 正 1 中性）

更新参考类：62% × 0.9（公司样本一致） ≈ **55% 到 65%**（Q1 yes 的外部视角概率）。

---

## 步骤 4 / 内部视角

`[步骤 4 / 内部视角]`

我想问你：

1. 这次实习你打算每周投多少小时？是否会受 C 语言期末复习挤压？
2. 你之前用 Claude Code 做 AI 工作流的经验，能直接迁移到他们的技术栈吗（你知道他们用什么吗）？

（用户回答：每周 15 小时，期末两周会断；自己之前主要用 Claude 不太熟他们用的 LangChain）

外部视角 60% → 内部视角 **48%**，调整原因：投入时长是参考类的一半多一点，加上技术栈迁移成本。

---

## 步骤 5 / 魔鬼代言人

`[步骤 5 / 魔鬼代言人]`

反方 1：「远程实习 + 大一身份」的组合，公司常把实习生放在外围打杂位（数据标注、文档整理），就算 JD 写了 LLM 接入，到岗后任务可能 2 周才落到你头上。

反方 2：你说「期末两周断」——你的子问题 Q2 截止日 8 月 15，正好覆盖期末后段，2 周断 = 至少损失 25% 有效工时，对独立 case 影响是非线性的（中断会丢上下文）。

反方 3：技术栈不熟意味着前 3 周大概率在追工具，真正做事的窗口只剩 4 到 5 周。

动摇你了吗？动摇多少？

（用户回答：反方 2 戳到了，期末断对我影响确实大）

## 节奏复盘

- 步骤 0 到 1 不超过 3 轮反问。这次用了 1 轮（一次反问两个问题）就拆出底层
- 步骤 3 是耗时大头。优先 web_search，搜不全才 BROK
- 步骤 5 反方理由必须给具体机制（远程 → 外围化 → 2 周才有任务），不要「也许会失败」
- 不替用户填「我的概率」。skill 给的是预测，不是决策
- 最终判断（去不去）不在 skill 里发生，由用户自己结合数字 + 价值观决定
